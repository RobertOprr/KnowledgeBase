# Imprimanta nu printează

## Simptom

Utilizatorul trimite o sarcină de printare, dar nimic nu se printează, sau
sarcina rămâne blocată în coadă.

## Cauze posibile

- Imprimanta este oprită sau offline.
- Imprimanta nu are hârtie sau cerneală/toner, sau are un blocaj de hârtie.
- O sarcină de printare blocată împiedică următoarele sarcini din coadă.
- Este selectată imprimanta greșită ca implicită.
- Driverul imprimantei este învechit, corupt sau lipsește.
- O imprimantă de rețea este inaccesibilă din cauza unei probleme de IP sau
  conectivitate.

## Rezolvare pas cu pas

1. Confirmă că imprimanta este pornită și afișează „Ready” pe display.
2. Verifică dacă există blocaje de hârtie, tăvi goale sau avertismente de
   cerneală/toner scăzut.
3. Confirmă că imprimanta corectă este selectată ca implicită pe
   dispozitivul utilizatorului.
4. Deschide coada de printare, elimină sarcinile blocate și încearcă să
   printezi o pagină de test.
5. Dacă imprimanta este în rețea, fă ping către adresa ei IP pentru a
   confirma că este accesibilă.
6. Repornește serviciul Print Spooler pe dispozitivul utilizatorului.
7. Reinstalează sau actualizează driverul imprimantei dacă problema
   persistă.
8. Printează o pagină de test direct din meniul propriu al imprimantei
   pentru a confirma că aceasta funcționează.
9. Confirmă că documentul original al utilizatorului se printează cu
   succes înainte de a închide tichetul.

## Când se escaladează

- Imprimanta este inaccesibilă în rețea și nu ai acces pentru a verifica
  starea switch-ului sau a portului.
- Problema afectează toți utilizatorii care încearcă să printeze la această
  imprimantă, ceea ce indică o problemă de driver partajat sau de server de
  printare.
- Imprimanta necesită o actualizare de firmware sau o reparație hardware.
- Probleme de server de printare sau spooler afectează mai multe imprimante
  simultan.
