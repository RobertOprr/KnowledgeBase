# Periferic nedetectat (tastatură, mouse, webcam, USB)

## Simptom

Un periferic conectat (tastatură, mouse, webcam, unitate USB sau
similar) nu este recunoscut de calculator.

## Cauze posibile

- Un cablu sau o conexiune slăbită ori defectă.
- Un port USB defect.
- Un driver lipsă sau învechit.
- Dispozitivul este dezactivat în Device Manager.
- Dispozitivul în sine este defect.

## Rezolvare pas cu pas

1. Confirmă că dispozitivul este conectat corect și încearcă un alt port
   USB.
2. Testează dispozitivul pe alt calculator, dacă este posibil, pentru a
   exclude un dispozitiv defect.
3. Verifică Device Manager pentru dispozitiv, căutând o iconiță galbenă de
   avertizare sau o intrare „Unknown Device”.
4. Dacă dispozitivul este dezactivat, activează-l din Device Manager.
5. Actualizează sau reinstalează driverul dispozitivului.
6. Repornește calculatorul și reconectează dispozitivul.
7. Dacă este un dispozitiv wireless, înlocuiește bateriile și
   repereche-ază-l.
8. Confirmă că dispozitivul funcționează conform așteptărilor înainte de a
   închide tichetul.

## Când se escaladează

- Dispozitivul nu funcționează pe mai multe calculatoare, ceea ce indică un
  dispozitiv defect care trebuie înlocuit.
- Device Manager arată o eroare hardware pe care actualizările de driver nu
  o rezolvă.
- Problema afectează un periferic specializat sau non-standard, în afara
  listei suportate de echipa ta.
- Portul în sine pare deteriorat fizic și necesită reparație hardware.
